# 🐍 Snake Game

A classic Snake Game recreated using **HTML, CSS, and JavaScript**. Control the snake using your keyboard, collect food to increase your score, and avoid hitting the walls.

### ✨ Features

* 🎮 Keyboard-based snake movement
* 🍎 Food collection and snake growth
* 🏆 Real-time scoring and persistent high scores using `localStorage`
* ⏱️ Game timer to track play duration
* 🔄 Restart functionality
* 🎨 Simple and interactive user interface

### 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage
